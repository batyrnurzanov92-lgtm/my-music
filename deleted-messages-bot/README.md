# Бот «Удалённые сообщения» (Telegram Business)

Бот сохраняет входящие сообщения из твоих личных чатов и присылает тебе:
- 🗑 **Удалено**: текст, от кого, когда было отправлено (фото, голосовые и т. п. он тоже пересылает);
- ✏️ **Изменено**: было → стало.

## Как это работает и ограничения
- Работает через **Telegram Business**: ты подключаешь бота к своему аккаунту, и Telegram сам присылает ему твои личные переписки.
- Когда сообщение удаляют, Telegram сообщает боту **только номер** сообщения, без текста. Поэтому бот заранее хранит копии в файле `messages.db` (SQLite) и при удалении достаёт текст оттуда.
- Видит только **личные чаты** (не группы, не каналы, не секретные чаты) и только сообщения, пришедшие **после** подключения бота.
- Твои собственные удалённые и изменённые сообщения бот не присылает.
- Премиум: раньше Telegram Business требовал Telegram Premium. По журналу изменений Bot API 10.0 (май 2026) ботам он больше не нужен. Если в настройках нет пункта «Чат-боты», значит, для твоего аккаунта Premium всё ещё нужен.
- ⚠️ Приватность: бот хранит чужие сообщения, в том числе те, которые человек решил удалить. Файл `messages.db` никому не передавай. По умолчанию копии старше 30 дней стираются (`KEEP_DAYS` в `.env`).

## 1. Создай бота и получи токен
1. В Telegram открой **@BotFather** и отправь `/newbot`. Придумай имя и username (должен заканчиваться на `bot`).
2. BotFather пришлёт **токен**: длинную строку вида `123456789:AA...`. Это пароль от бота. **Никому его не показывай** и не отправляй в чаты.
3. Там же включи бизнес-режим: `/mybots` → твой бот → **Bot Settings** → **Business Mode** (в новых версиях может называться **Secretary Mode**) → **Turn on**.

## 2. Запуск на Windows (PowerShell)
Открой PowerShell в папке с ботом и выполни по очереди:

```powershell
python -m venv .venv
```
```powershell
.\.venv\Scripts\python -m pip install -r requirements.txt
```
```powershell
Copy-Item .env.example .env
```
```powershell
notepad .env
```
В Блокноте замени `PASTE_YOUR_TOKEN_HERE` на свой токен, сохрани и закрой.

```powershell
.\.venv\Scripts\python bot.py
```
В консоли появится `Bot is starting`. Остановить бота: **Ctrl+C**. Бот работает, пока открыто окно и включён компьютер.

> `.venv` — отдельная «коробка» с библиотеками только для этого проекта, чтобы они не смешивались с другими.

## 3. Подключи бота к аккаунту
1. Найди своего бота в Telegram и нажми **Start**, иначе он не сможет тебе писать.
2. Настройки → **Telegram для бизнеса** → **Чат-боты** → введи username бота → выбери «Все личные чаты» (или нужные) → готово.
3. Бот пришлёт «✅ Бот подключён».
4. Проверка: попроси друга написать тебе сообщение и удалить его «у всех». Тебе придёт 🗑 с копией.

## 4. Где держать бота 24/7
Цены проверены в ноябре 2026 и быстро меняются, перед покупкой посмотри на сайте.

| Вариант | Цена | Комментарий |
|---|---|---|
| Свой компьютер | 0 | Бот работает только пока ПК включён. Для начала самое простое. |
| Oracle Cloud Always Free | 0 | Бесплатный сервер навсегда, но при регистрации нужна банковская карта, свободных серверов часто нет («Out of capacity»), а простаивающий сервер Oracle может удалить. Лимиты ARM в 2026 урезали. |
| Дешёвый VPS (например, Hetzner CX23) | около €5.5 в месяц | Надёжно. После подорожания в июне 2026 тариф иногда нельзя заказать. |
| PythonAnywhere | $10 в месяц (Developer) | На бесплатном тарифе бот круглосуточно работать не может: нужна платная «always-on task». |

Render, Railway и Fly.io больше не держат такие боты бесплатно: на бесплатных тарифах приложения засыпают, есть только пробный период, или нужна оплата.

На сервере (Linux) запуск такой же: `python3 -m venv .venv`, `.venv/bin/pip install -r requirements.txt`, `.venv/bin/python bot.py`. Чтобы бот сам перезапускался, оформи его как службу systemd.

## Почему не «юзербот»
Есть программы (Telethon, Pyrogram), которые входят в Telegram под твоим аккаунтом и видят вообще всё. Это **не рекомендуется**: правила Telegram это ограничивают, аккаунт могут заблокировать, а файл сессии даёт полный доступ к твоему аккаунту.

## Файлы
- `bot.py` — сам бот.
- `test_offline.py` — проверка без интернета: `.\.venv\Scripts\python test_offline.py`.
- `.env` — твой токен (в git не попадает, см. `.gitignore`).
- `messages.db` — сохранённые сообщения (создаётся сам).
