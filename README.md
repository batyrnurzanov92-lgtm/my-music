# Моя музыка

Своё музыкальное приложение без подписок и оплат. Работает на iPhone, Android и компьютере, а после установки и без интернета. Вся музыка хранится только на вашем устройстве.

## Что умеет (версия 1)

- Добавлять аудиофайлы (MP3, M4A/AAC, FLAC, WAV, OGG) по одному, пачкой или целой папкой (на компьютере). Название, исполнитель, альбом и обложка читаются из файла.
- Импортировать плейлисты и всю библиотеку из Apple Music / iTunes (`.xml`, `.txt`), CSV из TuneMyMusic / Soundiiz, а также `.m3u`.
- Сопоставлять песни: если добавить файл песни, которая уже есть в импортированном плейлисте, он сам встанет на её место.
- Добавлять песню вручную или по прямой ссылке на аудиофайл.
- Показывать библиотеку списком песен или плитками альбомов, искать и сортировать.
- Создавать плейлисты, переименовывать и удалять их, добавлять и убирать песни.
- Плеер: перемешивание, повтор, перемотка, управление с экрана блокировки и кнопками клавиатуры.
- Делать резервную копию списка песен и плейлистов (файл `.json`).

## Важно знать

- Звук песен из подписки Apple Music защищён (DRM) и не переносится. Переносятся названия и порядок песен, а звук берётся из ваших собственных файлов.
- Библиотеки на телефоне и компьютере отдельные. Перенести список можно через резервную копию.
- Если браузеру не хватит места, он может удалить данные. Приложение просит браузер так не делать, но аудиофайлы лучше хранить и у себя.

## Как запустить на компьютере (для проверки)

1. Откройте папку проекта.
2. Нажмите правой кнопкой на `tools\serve.ps1` → «Выполнить с помощью PowerShell».
3. Откроется браузер с адресом `http://localhost:8765`. Окно PowerShell не закрывайте, пока пользуетесь приложением.

## Как поставить на телефон

Телефону нужен адрес в интернете (https). Бесплатный вариант: GitHub Pages.
1. Создайте бесплатный аккаунт на github.com.
2. Загрузите туда эту папку и включите Pages. Это следующий шаг, сделаем его вместе.
3. Откройте полученный адрес на телефоне:
   - **iPhone:** в Safari → «Поделиться» → «На экран Домой».
   - **Android:** в Chrome → меню ⋮ → «Установить приложение».

## Как устроен код

| Файл | Что делает |
|---|---|
| `index.html` | Каркас страницы: место для экранов, мини-плеер, вкладки, полноэкранный плеер |
| `style.css` | Внешний вид: тёмная тема, красно-розовый цвет, высокий контраст |
| `js/db.js` | Хранилище на устройстве (IndexedDB): песни, файлы, обложки, плейлисты |
| `js/tags.js` | Чтение названия, исполнителя и обложки из аудиофайлов |
| `js/importers.js` | Чтение экспортов Apple Music / iTunes, CSV и M3U |
| `js/app.js` | Экраны, плеер, импорт и все кнопки |
| `sw.js` | Работа без интернета (сохраняет копию приложения) |
| `manifest.webmanifest`, `icons/` | Название и значок для установки на главный экран |
| `tools/serve.ps1` | Маленький локальный сервер для проверки на компьютере |

## Дальнейший план

1. Опубликовать на GitHub Pages и поставить на телефон.
2. Очередь воспроизведения («что дальше»), перетаскивание песен в плейлисте.
3. Перенос музыки между телефоном и компьютером одним файлом (вместе со звуком).
4. Настройки: размер текста, выбор оттенка.
